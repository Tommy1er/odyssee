# Installation du dépôt dédié
1. Le propriétaire crée le dépôt GitHub `Tommy1er/odyssee-research` **privé**, initialisé par README sur main, sans importer le moteur ou son historique.
2. Autoriser le connecteur GitHub de ChatGPT uniquement sur ce nouveau dépôt pour la mise en place ; transférer le contenu de `research-lab/` de la branche d'amorçage à la racine (ne jamais fusionner cette branche dans le dépôt production).
3. Vérifier intégrité des fichiers, protections main et règles de sécurité ; créer les issues de qualification et le Project (PILOTAGE.md), sans inviter en écriture à la production.
4. Vérifier chaque identité et accès ; n'envoyer les mandats qu'après qualification et gel V3.0. Ne pas publier de secret, code source privé ou document sous droits. La préparation seule ne lance aucun agent.
5. Après transfert validé, la branche d'amorçage peut être archivée/supprimée sur décision explicite du propriétaire.
