# Odyssée Research Lab — ORL / V4 Univers vivant

**Statut : AMORÇAGE — aucun mandat scientifique lancé, aucun accès externe qualifié, aucun GO de production.**

Bienvenue. ORL est le laboratoire de recherche indépendant de l'application [Odyssée](https://github.com/Tommy1er/odyssee). Objectif : rendre les mouvements, activités locales et interactions astrophysiques observables, avec preuves, limites et budgets de calcul explicites. La version V3.0 publique doit d'abord être stabilisée ; le SHA scientifique définitif sera approuvé après ce gel.

## Parcours obligatoire
1. Lire [la gouvernance](00_GOUVERNANCE/CHARTE.md), [les règles d'accès](00_GOUVERNANCE/ACCES.md) et [la procédure de contribution](00_GOUVERNANCE/CONTRIBUTIONS.md).
2. Consulter [le référentiel](01_REFERENTIEL/BASELINE.md) et [le programme V4](01_REFERENTIEL/PROGRAMME-V4.md).
3. Trouver son mandat dans [le registre des agents](02_CONTRIBUTIONS/README.md).
4. Réussir les tests de qualification et attendre l'autorisation de lancer le tour 1.
5. Déposer une contribution autonome ; utiliser les modèles de rapport, sources, prototype, revue et validation. Aucun agent ne doit publier en production.

## Structure
- 00_GOUVERNANCE : mandat, responsabilités, accès, processus, benchmark.
- 01_REFERENTIEL : baseline et programme.
- 02_CONTRIBUTIONS : huit espaces d'agents.
- 03_SOURCES_SCIENTIFIQUES : registre de données, sources, licences.
- 04_PROTOTYPES : règles des démonstrateurs autonomes.
- 05_CONTRE_EXPERTISES : revues par les pairs et contradictions.
- 06_VALIDATION : tests, preuves et qualification.
- 07_NOTE_MASTER : synthèse et décisions proposées.
- 08_DECISIONS : arbitrages du propriétaire.
- 09_TRANSFERT_PRODUCTION : paquets approuvés pour Claude/Codex.
- templates : formulaires versionnés.

## Particularité de cet amorçage
Ce dossier est préparé sur la branche `research-lab-bootstrap` du dépôt existant. Il est **public en lecture comme le dépôt parent** ; il ne constitue pas une isolation des permissions. Ne pas inviter les agents en écriture sur le dépôt de production. Copier le contenu de ce dossier (et non l'historique/moteur de production) dans le dépôt distinct `Tommy1er/odyssee-research` à créer. Ne jamais fusionner cette branche sur `main`. L'activation du laboratoire, les protections, les Issues et le Project nécessitent une vérification de configuration dans le nouveau dépôt. Aucun secret ni donnée personnelle dans cette branche.
