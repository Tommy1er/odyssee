# Odyssée

Lire `COLLABORATION.md` pour le lancement, l’architecture, les tests, les limites scientifiques et le travail commun avec Codex. Le manuel utilisateur courant est `public/physics-v2.html` ; les notes historiques de README ne priment pas sur les fonctionnalités actuelles.

Le projet fonctionne localement sans clé API. Modifier les sources puis lancer `npm run build`. Conserver les attributions des assets et les distinctions entre observations, modèles et fiction. Un seul dépôt `Tommy1er/odyssee`, une seule branche `main`, chacun à son tour. Récupérer le dernier `main` avant de modifier, vérifier puis faire un commit et un push avant le relais. Ne pas créer de branche parallèle ni forcer un push. Documenter les vérifications réellement exécutées. Hébergement conservé sur ChatGPT Sites ; Codex publie la dernière version GitHub lorsque Abdoulaye le demande.
